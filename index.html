Daftar Tugas

Pola paling umum di JS: simpan data di array, lalu tulis ulang tampilan setiap kali data berubah.

    Belum ada tugas. Coba tambah satu.

    Lihat kode 
    <span class="cm">// Data disimpan sebagai array of object, bukan langsung di HTML</span>
let tugas = [];

function renderTugas() {
  todoList.innerHTML = ""; <span class="cm">// kosongkan dulu, lalu gambar ulang</span>
  todoEmpty.style.display = tugas.length ? "none" : "block";

  tugas.forEach((item) => {
    const li = document.createElement("li");
    if (item.done) li.classList.add("done");

    const span = document.createElement("span");
    span.textContent = item.text;
    span.onclick = () => { <span class="cm">// klik teks = toggle selesai</span>
      item.done = !item.done;
      renderTugas();
    };

    const hapus = document.createElement("button");
    hapus.textContent = "✕";
    hapus.onclick = () => {
      tugas = tugas.filter((t) => t.id !== item.id);
      renderTugas();
    };

    li.append(span, hapus);
    todoList.appendChild(li);
  });
}

todoForm.addEventListener("submit", (e) => {
  e.preventDefault(); <span class="cm">// cegah form reload halaman</span>
  const teks = todoInput.value.trim();
  if (!teks) return;
  tugas.push({ id: Date.now(), text: teks, done: false });
  todoInput.value = "";
  renderTugas();
});

    Ganti Tema

    Warna di situs ini diatur lewat variabel CSS (--accent, --bg, dst). Ganti atribut data-theme di <body>, dan seluruh palet warna ikut berubah — tanpa sentuh elemen satu-satu.

    Lihat kode 
    <span class="cm">/* Di CSS: definisikan ulang variabel untuk tiap tema */</span>
[data-theme="hutan"] {
  --bg: #10160f;
  --accent: #7bbf5e;
  /* ...dst */
}

<span class="cm">// Di JS: cukup ganti satu atribut di elemen <body></span>
document.querySelectorAll("[data-theme-btn]").forEach((btn) => {
  btn.addEventListener("click", () => {
    const nama = btn.dataset.themeBtn;
    document.body.setAttribute(
      "data-theme",
      nama === "default" ? "" : nama
    );
    <span class="cm">// tandai tombol yang aktif</span>
    document.querySelectorAll("[data-theme-btn]")
      .forEach((b) => b.classList.remove("active"));
    btn.classList.add("active");
  });
});
    classList + aria

    Accordion FAQ

    Trik animasi tinggi yang "tidak diketahui" (auto) dengan CSS: transisi max-height ke nilai scrollHeight asli konten.

    Supaya gampang dibaca dari atas ke bawah saat belajar. Di proyek nyata, HTML/CSS/JS biasanya dipisah ke file berbeda.

    Pola memasang satu event listener di elemen induk, lalu memeriksa event.target untuk tahu elemen anak mana yang diklik — lebih hemat daripada pasang listener di tiap anak.

    Boleh banget. Silakan ambil bagian mana pun, ganti nama variabel dan gaya sesuai proyekmu.

    Lihat kode 
    document.querySelectorAll(".acc-toggle").forEach((btn) => {
  btn.addEventListener("click", () => {
    const panel = btn.nextElementSibling;
    const buka = btn.getAttribute("aria-expanded") === "true";

    btn.setAttribute("aria-expanded", String(!buka));
    panel.style.maxHeight = buka ? null : panel.scrollHeight + "px";
    btn.querySelector(".plus").textContent = buka ? "+" : "−";
  });
});
    canvas API + mouse events

    Papan Coret

    Menggambar itu sebenarnya cuma menyambung banyak garis pendek setiap posisi kursor bergerak selagi tombol mouse ditekan.

    Lihat kode 
    const ctx = doodle.getContext("2d");
let menggambar = false;

function posisi(e) {
  const rect = doodle.getBoundingClientRect();
  const titik = e.touches ? e.touches[0] : e;
  return { x: titik.clientX - rect.left, y: titik.clientY - rect.top };
}

function mulai(e) {
  menggambar = true;
  const { x, y } = posisi(e);
  ctx.beginPath();
  ctx.moveTo(x, y);
}

function gambar(e) {
  if (!menggambar) return;
  const { x, y } = posisi(e);
  ctx.strokeStyle = doodleColor.value;
  ctx.lineWidth = doodleSize.value;
  ctx.lineCap = "round";
  ctx.lineTo(x, y);
  ctx.stroke();
}

function selesai() { menggambar = false; }

doodle.addEventListener("mousedown", mulai);
doodle.addEventListener("mousemove", gambar);
window.addEventListener("mouseup", selesai);

doodleClear.addEventListener("click", () => {
  ctx.clearRect(0, 0, doodle.width, doodle.height);
});
    event hover + click

    Rating Bintang

    Kombinasi mouseover untuk pratinjau dan click untuk menetapkan nilai — pola yang sama dipakai di rating produk e-commerce.

    Arahkan kursor lalu klik untuk memberi nilai.

    Lihat kode 
    let nilai = 0;
const jumlahBintang = 5;

for (let i = 1; i <= jumlahBintang; i++) {
  const btn = document.createElement("button");
  btn.textContent = "★";
  btn.dataset.nilai = i;

  btn.addEventListener("mouseenter", () => tandai(i));
  btn.addEventListener("mouseleave", () => tandai(nilai));
  btn.addEventListener("click", () => {
    nilai = i;
    ratingText.textContent = `Kamu memberi ${nilai} dari 5 bintang.`;
  });

  stars.appendChild(btn);
}

function tandai(sampai) {
  [...stars.children].forEach((btn, idx) => {
    btn.classList.toggle("filled", idx < sampai);
  });
}
    regex + validasi langsung

    Validasi Form

    Umpan balik yang muncul sambil mengetik (bukan setelah submit) bikin form terasa lebih responsif. Ini dasar dari validasi di hampir semua form modern.

    Lihat kode 
    const polaEmail = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

emailInput.addEventListener("input", () => {
  const valid = polaEmail.test(emailInput.value);
  emailInput.classList.toggle("ok", valid && emailInput.value !== "");
  emailInput.classList.toggle("bad", !valid && emailInput.value !== "");
  emailMsg.textContent = emailInput.value === ""
    ? ""
    : (valid ? "Format email valid." : "Format email belum benar.");
  emailMsg.className = "msg " + (valid ? "ok" : "bad");
});

passInput.addEventListener("input", () => {
  const v = passInput.value;
  let skor = 0;
  if (v.length >= 8) skor++;
  if (/[A-Z]/.test(v)) skor++;
  if (/[0-9]/.test(v)) skor++;
  if (/[^A-Za-z0-9]/.test(v)) skor++;

  const persen = (skor / 4) * 100;
  strengthFill.style.width = persen + "%";
  strengthFill.style.background =
    skor <= 1 ? "var(--danger)" : skor <= 3 ? "var(--accent)" : "var(--accent-2)";

  const label = ["Sangat lemah", "Lemah", "Cukup", "Kuat", "Sangat kuat"][skor];
  passMsg.textContent = v === "" ? "" : label;
});

    Ide buat kamu otak-atik

    • Ganti nilai --accent di bagian atas CSS, lihat efeknya ke semua modul sekaligus.
    • Tambah tema keempat: salin blok [data-theme="laut"], ganti namanya dan warnanya, lalu tambah tombolnya di HTML.
    • Di modul Daftar Tugas, tambahkan fitur "hapus semua yang selesai".
    • Di Papan Coret, tambahkan tombol untuk mengunduh gambar (petunjuk: canvas.toDataURL()).
    • Di Rating Bintang, ganti bintang jadi emoji lain dan lihat apakah animasinya masih masuk akal.
